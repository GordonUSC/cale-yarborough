# cale-yarborough

A gift concept from Gordon Bellamy’s team for Cale Yarborough.

- `for-cale/index.html`: the invitation, with two choices each for Cale’s site and Pizza Baby.
- `index.html`: Ideas Become Places, the work and production perspective.
- `experience.html`: The Room We Make, with Feel, Think and Belong intentions.

Serve this static repository with any static HTTP server. No build step or dependencies are required. Keep the existing art, audio and fonts directories in place. Artwork is labeled in each page; the friendship photograph, schedule and Gryphus mark are real.
